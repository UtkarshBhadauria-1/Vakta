# Report sources

1. Lewis, Patrick, et al. “Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks.” NeurIPS 2020. The paper describes generation conditioned on retrieved passages; it supports the architectural background, not a performance claim about Vakta. https://arxiv.org/abs/2005.11401
2. Reimers, Nils, and Iryna Gurevych. “Sentence-BERT: Sentence Embeddings using Siamese BERT-Networks.” EMNLP-IJCNLP 2019, pp. 3982–3992. The paper describes semantically meaningful sentence embeddings and cosine-similarity use. https://aclanthology.org/D19-1410/
3. Johnson, Jeff, Matthijs Douze, and Hervé Jégou. “Billion-scale similarity search with GPUs.” arXiv:1702.08734, 2017. The paper describes nearest-neighbor similarity-search methods; it does not benchmark this project’s CPU FAISS setup. https://arxiv.org/abs/1702.08734
4. HCLTech Career Shaper Programme. “AI-Powered Chatbot for University Student Support — III Year Industry Project, Project 30, Project Brief.” User-supplied document, academic year 2025–26. Local project file: `Project_Brief-Vakta.docx`.

The web sources were opened and checked on 27 October 2026. The project report cites them only for technical background; project-specific outcomes are based on local code, tests, data, and evaluation outputs.
